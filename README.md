## Cine mode

`?cine=1` turns the game into a small film set: a looping sequence of four directed shots (opening
crane, walking journey, dusk lantern lighting, night close-up), and **R** exports the whole run as a
deterministic image-frame sequence ready for ffmpeg. See [docs/CINE.md](docs/CINE.md).
